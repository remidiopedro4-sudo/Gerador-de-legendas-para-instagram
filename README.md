# Legenda — Gerador de legendas para Instagram

Aplicação React + Vite que transforma uma frase ou ideia em três sugestões de legenda, com cinco parágrafos cada.

## Sem API e sem chave externa

A geração acontece diretamente no navegador por meio de estruturas e variações locais. Não é necessário cadastrar chave, configurar faturamento ou conectar um serviço externo. O conteúdo digitado não é enviado a uma API de IA.

**Observação:** por funcionar sem um modelo de linguagem externo, a geração é baseada em estruturas e variações predefinidas. Ela não tem a mesma capacidade de compreensão e adaptação de um ChatGPT.

## Executar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
